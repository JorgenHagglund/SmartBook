## This is a simple librarian console program for managing books.
With it, you can:
- Add a book
- Remove a book, based on title or ISBN.
- Search for books, based on author, title or ISBN.
- List books sorted by author, title, ISBN.
- List books that are currently checked out.
- Check out, and in, a book.

## Extra features include
- Loading and saving the library to a file.
- Some basic logging

## Tests that have been done, using xUnit testing
- Adding a book
- Validating ISBN both for success and failure

## How to run the program
1. Clone the repository
1. Build the solution
1. Make sure the project SmartBook is set as the startup project
1. Run the program
1. The rest is self explanatory
